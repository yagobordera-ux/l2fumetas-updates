# L2FUMETAS - actualizaciones del cliente (servidor l2ganjah)

Repositorio de distribucion del launcher L2FUMETAS. Contiene manifest.json y manifest.sig (firmados con RSA por L2FUMETAS) y, en Releases, los ficheros del parche nombrados por su SHA-256. El launcher rechaza cualquier fichero o manifiesto que no verifique la firma.
